## From the simulator to the robot, in one language

A robot-learning project today is assembled from pieces that were never meant
to meet: MuJoCo for physics, PyTorch for networks, LeRobot for datasets and
policies, a vendor SDK for the motors, and whatever runtime fits on the robot's
computer. Every seam costs something — copies across language boundaries,
versions that drift, a policy that behaves differently on the robot than it
did in training because the code that ran it was not the code that trained it.

noeira builds the whole loop in Mojo instead: the physics engine, the task
suites, the neural networks, the learning algorithms, the camera pipeline, the
servo bus and the deployment runtime. The policy that trains on a GPU in the
cloud is the same code that drives the arm from a Jetson.

## What is inside

<CardGrid>
	<Card title="Simulation" icon="setting">
		A MuJoCo-inspired 3D engine validated against live MuJoCo — Menagerie
		robots, DeepMind Control, meshes, tendons, elliptic contacts — with
		batched GPU stepping and ray-traced cameras. See
		[3D physics](/physics/physics3d/) and [environments](/environments/).
	</Card>
	<Card title="Tasks and benchmarks" icon="list-format">
		A declarative task layer — families, goals, placements — that runs many
		tasks in one batched scene. LIBERO's suites are ported onto it; the
		SO-101 has its own tabletop and tower families.
	</Card>
	<Card title="Learning" icon="star">
		Reinforcement learning from tabular methods to SAC and PPO, world models
		(TD-MPC2, DreamerV3, Dreamer 4), MCTS planners, and zero-shot
		Forward-Backward. See [algorithms](/algorithms/).
	</Card>
	<Card title="Imitation and VLAs" icon="random">
		ACT and SmolVLA trained and run in Mojo, behaviour cloning, and
		HIL-SERL with DAgger-style interventions — learning from demonstrations
		recorded in simulation or on the real arm.
	</Card>
	<Card title="Robots" icon="rocket">
		The SO-101 arm over its servo bus: calibration, teleoperation, recording
		to LeRobot v3 datasets with cameras, and policies deployed on a Jetson
		Orin.
	</Card>
	<Card title="Infrastructure" icon="puzzle">
		[`noeira.nn`](/nn/) — autodiff, 70+ primitives, fused and flash
		attention, AMP and CUDA graphs — plus native HDF5, Parquet and video I/O,
		and [noeira cloud](/tooling/monitor/) for runs and datasets.
	</Card>
</CardGrid>

:::note[Project status]
noeira is developed in the open and was selected for a
**Modular Community Grant** in 2026. Maturity differs by area, and every page
carries its own marker:

- **Stable:** the 3D physics engine and its MuJoCo validation, the classic
  and MuJoCo-style environments, DQN / PPO / SAC / TD3, `noeira.nn`.
- **Beta:** the task layer and LIBERO, ACT (trained and deployed on the real
  arm), recording to LeRobot, Jetson deployment.
- **Experimental:** SmolVLA on the arm, HIL-SERL and DAgger, the world-model
  agents, DeepMind Control training. Results are reported with their caveats
  on each page.
:::
