# ── mojo_rl/tasks: the per-lane ACTIVE MASK and the obs (P3d) ───────
# ⚠ RUNS THE REAL HOOK, ON THE CPU AT float64. `custom_extract_obs_gpu` is
# generic over dtype and origin, so the gate instantiates the config's own
# observation writer rather than a re-spelling of it.
# ⚠⚠ IT ALSO CHECKS A RESTATEMENT. `So101TabletopConfig` restates the free
# slots' qposadr/dofadr because a comptime type cannot read a runtime
# `.family`; this resolves them out of the composed scene and asserts every
# one. ABLATED three ways — lane-0 mask for every lane (3 of 16 fail, and the
# negative leg is the only check that sees it), flag-without-zeroing (2), and
# a drifted address table (3).
# ⚠ ALSO GATES GAP D (the per-step repark) and, with it, a TRAIT CHANGE: the
# env now calls only `pre_step_full_gpu`, so the fourteen configs that override
# the narrow `pre_step_gpu` depend on its default forward. The gate calls the
# WIDE hook on `HalfCheetahConfig` and asserts its META_IDX_PREV_X write lands
# per lane — a broken forward is otherwise silent, because the stashed value
# is not read until the reward and the reward merely goes stale. ABLATED:
# pose-without-velocity (1 of 24), pinning every slot (1), skipping the
# quaternion (1), dropping the forward (2 — and only the HalfCheetah leg sees
# it).
tests/tasks/test_active_mask.mojo

# ── mojo_rl/tasks: per-task success, and what reaches the monitor (P4b) ──
# ⚠⚠ `same_as` COMPARES LANES, NOT RATES, and the gate builds the pair that
# separates them: two runs with identical per-task rates on disjoint lanes. A
# rate comparison passes that, which is the whole reason the check exists.
# ⚠ The metrics are read back OFF DISK through CsvLogger, episode counts
# included — a rate with no denominator cannot be told from the same rate over
# a third as many episodes. ABLATED: a rate-based `same_as` (1 of 16 fails), a
# per-task denominator that logs the LANE count instead (2), and an
# unrecorded lane counted as a failure (1). The two tasks deliberately get
# UNEQUAL episode counts — at 5 and 5 the wrong denominator reads as right.

# ── mojo_rl/tasks: is `reach` REACHABLE, and by how much ────────────
# ⚠⚠ THE GATE NO OTHER TASK GATE CAN BE. Everything else here asks whether a
# goal EVALUATES; this asks whether a policy could ever MEET it — the fraction
# of the arm's configuration space inside `AtRegion(robot_gripperframe,
# table_top)`, over 4096 uniform draws. A satisfiable-but-tiny target set and
# a healthy one look identical to every other check, and the difference is a
# task that trains against one that gives a flat curve read as an agent bug.
# Measured: 3.2% of uniform poses; the floor it asserts is 0.5%.
# ⚠ IT FOUND THE ANGLE-UNIT DEFECT. Before the composed scene restated
# `<compiler angle="radian">` the hit rate was 0 and the arm's travel was
# +-1.9 DEGREES — with nbody, njnt, nq, nv, ngeom and every contact count
# correct. `test_family_compose_vs_mujoco` now holds that half open directly.
# ABLATED: with the angle line removed the sweep's envelope collapses to
# 0.07 m and the hit rate goes to 0 (the span control fires first).
examples/tasks/task_reachability.mojo
