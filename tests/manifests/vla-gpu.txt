# SmolVLA manifest (GPU) — `pixi run -e apple test-vla-gpu` (or -e nvidia)
#
# The companion to `vla.txt`: a name map over a module tree that cannot execute
# proves very little, so these construct the real shapes and run them.

# Step 2 — the vision tower forward + vjp at 512x512 -> 1024 x 768.
tests/deep_agents/smolvla/test_vision_forward_smoke.mojo

# Step 3 — the RoPE leaf vs MAX's shipped `rope_ragged`, the adjoint identity,
# and our own CPU/GPU parity. Needs a GPU because the reference kernel is one.
tests/nn/test_rope_vs_max_kernel.mojo

# Step 4 — PixelShuffle (1024x768 -> 64x12288) vs an independent re-derivation
# of the reference's five view/permute steps, plus bijection and adjoint.
tests/nn/test_pixel_shuffle.mojo

# Step 6 — the static prefix KV cache: per-layer isolation, [prefix; suffix]
# scratch, the prefix surviving ten denoising steps unchanged, the unfilled-read
# guard, and GPU/CPU parity of the sub-buffer copies.
tests/deep_agents/smolvla/test_kv_cache.mojo

# Step 6 — the prefill pass: 16 layers filling the KV cache. Checks the cache
# CONTENTS (all layers written, all distinct, post-RoPE and pre-broadcast), not
# just that it ran — every interesting failure here produces finite output.
tests/deep_agents/smolvla/test_prefill.mojo

# Step 6 — the static-mask attention the denoising step needs, gated against the
# torch-validated CrossAttention on the unmasked case.
tests/deep_agents/smolvla/test_block_attention.mojo

# V2 — that leaf's BACKWARD, against central differences of the definition in
# Float64. Every one of the 1,472 input components is probed, not a sample,
# because a wrong attention gradient is finite, correctly shaped and silent:
# it shows up as a fine-tune that learns worse, months later. The file records
# four measured ablations, including one that dV alone would have missed.
tests/deep_agents/smolvla/test_block_attention_vjp.mojo

# Step 6 — one denoising step and then ten, over a prefilled cache. Asserts the
# cache is bit-identical after ten steps and that repeated steps do not drift:
# the crop bug does not crash, it quietly changes the chunk.
tests/deep_agents/smolvla/test_denoise.mojo

# Step 7 — the flow-matching Euler schedule, pinned analytically: with a constant
# velocity the integral is exactly -c, which catches a flipped dt, a wrong step
# count and a wrong magnitude at once. Plus the per-token concat.
tests/deep_agents/smolvla/test_flow.mojo

# Step 7 — the whole V1 inference path: prefill, then ten Euler steps to an
# action chunk. Asserts the output MOVED off the noise, that ten steps differ
# from one, and that a rerun reproduces exactly (no state mutated between calls).
tests/deep_agents/smolvla/test_sample_actions.mojo

# Step 7 — prefix assembly: the segments land where the mask expects, and only
# image+language carry the sqrt(960) scale (the state must not).
tests/deep_agents/smolvla/test_prefix_embed.mojo

# The assembled policy: every component in one object, raw frames + a pose to
# a chunk of joint angles. Gates the WIRING, which no component gate can see —
# `P` derived once and handed to the cache and all three masks, the dataset
# scale applied per dimension (checked by doubling only action_std, since
# "the values look big" does not decide), and above all that the KV cache
# belongs to ONE observation: a new scene must give a new chunk, and a
# repeated one must reproduce exactly. Seeded weights, no download.
# ⚠ ~4 min, nearly all compile — one instantiation of all 44 layers.
tests/deep_agents/smolvla/test_policy.mojo
