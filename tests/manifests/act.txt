# ACT manifest — `bash scripts/run_tests.sh tests/manifests/act.txt`
#
# ⚠ NOT part of `test-smoke`. Every gate below except the overfit probe reads a
# reference dump produced from `references/act-main/` under PyTorch, and the
# smoke tier is defined as self-contained (no references/, gitignored and absent
# on CI). The overfit probe IS self-contained but takes ~80 s, which the smoke
# tier is not for either.
#
# Prerequisites:
#
#   pixi run -e act-ref python tools/act/dump_act_reference.py --out /tmp/act_ref
#   pixi run -e act-ref python tools/act/dump_resnet18_imagenet.py \
#       --out ~/.cache/mojo_rl/act_so101/resnet18_imagenet
#   pixi run python tools/act/lerobot_v3_to_store.py \
#       --repo DenisLabs/record-test_20260828_092736 --height 240 --width 320
#
# The dataset gate takes ANY store at 240x320 — `$ACT_STORE` if set, else the
# newest one in the cache. It pins no row or episode count; see its header.
#
# ⚠ These run under `mojo run` (JIT), which never invokes ld. Building them with
# `mojo build` needs `-Xlinker -ld_classic`: the fully-expanded ResNet18 / graph
# types mangle to symbols longer than Apple's new linker accepts. Healthy source,
# toolchain limit — see feedback_mojo_build_failure_can_be_link_only.
